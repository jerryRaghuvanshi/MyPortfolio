## 🚀 Featured Engineering Highlights

- **Strangle – Production Real-Time Voice/Video Discovery Platform**:
  - High-concurrency matchmaking engine built with Java 21, Spring Boot, and Redis (Lua scripts, Sorted Sets, distributed locks).
  - WebRTC audio/video calling with STOMP WebSockets signaling and Coturn (STUN/TURN) NAT traversal.
  - Asynchronous event-driven messaging layer with RabbitMQ, PostgreSQL, MinIO presigned media storage, and automated ephemeral data shredding.
  - Decoupled Python (FastAPI) Trust & Safety moderation service.
  - AWS EC2 Docker Compose deployment, Caddy reverse proxy (automated Let's Encrypt TLS), and GitHub Actions CI/CD.

- **Amazon-Inspired E-Commerce Backend**:
  - Containerized Spring Boot backend with Stripe Payment Intents & webhooks, Redis caching, MySQL indexing, and JWT security.

- **Enterprise Expense Tracker**:
  - Full-stack finance management platform with dual JWT & Google OAuth 2.0, MapStruct DTOs, dynamic analytics, and OpenAPI documentation.

- **Task Manager REST API**:
  - Secure REST API with Spring Security, RBAC ownership checks, and OpenAPI/Swagger docs.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/jerryRaghuvanshi/MyPortfolio.git
cd MyPortfolio

# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
